# UX Quant Study Roadmap

## Goal
Build a portfolio that shows quantitative UX research, SQL fluency, and practical product thinking.

## What to Practice
- Research question framing
- Data cleaning and validation
- Descriptive statistics and visualization
- Hypothesis testing
- Regression and segmentation
- SQL for analytics and reporting
- Writing concise findings and recommendations

## Core Datasets
1. Survey questionnaire data
2. Usability testing data
3. A/B testing data
4. Feature adoption data
5. System UX metrics data

## Weekly Plan
### Week 1: Foundations
- Learn the dataset structure
- Write a data dictionary
- Clean one dataset
- Build summary tables and charts
- Practice SQL basics: SELECT, WHERE, ORDER BY, GROUP BY

### Week 2: Research Analysis
- Analyze survey and usability datasets
- Compare groups and compute effect sizes
- Practice joins and aggregations in SQL
- Write one short insight memo per dataset

### Week 3: Experiment and Product Metrics
- Analyze A/B testing and feature adoption data
- Practice CTEs, window functions, cohorts, and funnels
- Write product recommendations based on results

### Week 4: Publish and Polish
- Improve notebooks and README files
- Add figures and a short executive summary
- Publish to GitHub
- Prepare resume bullets and LinkedIn posts

## Practice Routine
- 30 minutes SQL
- 60 minutes analysis
- 30 minutes writing
- 15 minutes review

## Deliverables
- Clean notebook
- README with problem, method, result, and recommendation
- Figures folder
- Short summary for recruiters
